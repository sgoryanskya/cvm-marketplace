# билайн бизнес · маркетплейс CVM

Прототип: https://sgoryanskya.github.io/cvm-marketplace/

## Где что лежит

- `index.html`, `assets/` — сборка, ее раздает GitHub Pages. Руками не править.
- `knowledge.json` — плашки раздела «База знаний». Править можно прямо в GitHub, пересборка не нужна.
- `app/` — исходники (React 18, TypeScript, Vite).

## Как поменять ссылку в «Базе знаний»

1. Открыть `knowledge.json` в GitHub, нажать карандаш.
2. Найти плашку по `title`, вставить адрес в `link`.
3. Сохранить (Commit changes). Сайт обновится через минуту-две.

Пустой `link` — плашка «скоро», без перехода. `order` — порядок внутри группы. `group`: `understand` (разобраться, с номерами) или `work` (работать). Название до 30 знаков, текст до 60.

## Как собрать

```
cd app
npm install
npm run dev      # локально, http://localhost:5173
npm run build    # сборка в корень репозитория
```

На Mac можно дважды нажать `app/открыть приложение.command`.

Данные заявок и профиля хранятся только в браузере (localStorage), бэкенда нет.
